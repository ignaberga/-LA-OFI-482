# Archivo

Versiones anteriores que ya no se usan, guardadas por si se quieren recuperar.

- `stockbares-v1-control/`: primera versión de la app de stock de bares
  (septiembre 2026). Además del conteo tenía compras, ventas por trago con
  medidas, pases, bajas y un control de faltantes (conteo anterior + compras −
  ventas vs. conteo nuevo). Se reemplazó por una app solo de conteo porque
  las compras y las ventas ya están en el sistema de gestión de Noel.
  Usa otro prefijo en el celular (`stockbares_v1_`) para no mezclarse con la
  versión actual.
